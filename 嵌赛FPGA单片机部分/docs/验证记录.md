- 记录一处与交接文档不一致的结论：APB1 = 45 MHz 下 USART2 的 2 Mbit/s **不是零误差**（USARTDIV = 1.40625，BRR 只能取 22 → 2.0455 Mbit/s，+2.27%）。在 UART 容限内可以通信，但若上板出现 framing error，应改用 APB2 90 MHz 的 USART6（PC7/DMA2_Stream1 CH5，误差为 0）。详见 `docs/B板可视化_MCU接入说明.md` 第 3 节。
- 追加（**XY 页可读性**，仅 `viz_view.c`）：按 `xy_scope.sv` 的定义在页面顶部用两种颜色标出 **X = x[n]**（青）与 **Y = x[n − T/4]**（琥珀，比例取自 STAT 第 6/7 字节），说明两端来自同一单声道；方框 352→**312×312**，内部加 1/4 网格与中心轴，左侧为 Y 轴、下方为 X 轴，各 5 个刻度（`+1.00 / +0.50 / 0 / −0.50 / −1.00`，按增益折算，避免 `%f` 用整数定点格式化）。刻度含义：相对 16 位满量程，`1.00 = ±32768`，1 个码 = 256 LSB，中心 = 静音(0x80)。网格与刻度线每帧重画（否则会被迹线的背景色擦出洞），文字只在清屏后画一次。排版用真实坐标做了 800×480 的定位预览核对无重叠（`docs/viz_xy_layout.png`）。编译链接 0 Error。
- 本机未执行烧录。**未验证**：B 板到 PA3 的 2 Mbps 实体通信与误码率、第三页实际观感/触摸命中/帧率、与 1 Mbps 压力链路同时满载时的抖动。第 9 节的上板顺序与排错表仍需实机走一遍。
- 追加（显示可读性，仅 `viz_view.c`）：WAVE 由"3 px 一列实心竖条"改为在列间线性插值到 **760 个 1 px 竖条**（min/max 跨度 >2 px 时画暗青色包络 + 2 px 亮色中心迹线），台阶宽度由 3 px 降到 1 px，协议与 B 板不动；新增顶栏 **Gain x1/x2/x4** 循环按钮与 `CLIP!` 削顶提示（8 位偏移二进制按 16 位全量程换算，正常电平只占几十个码值）；XY 改为 **352×352 正方形等比映射**（原来 760×352 把圆压成 2.16:1 扁椭圆）并加中心十字。重新编译链接仍为 0 Error。实际观感需上板确认。
- 追加（帧率问题，仅 `viz_view.c`）：上板反馈 WAVE/XY 只有 5–9 fps。核对 B 板 `viz_top.sv` 后确认源端仍是每块 21.33 ms 发一帧（≈47 fps），瓶颈在 MCU 绘制：一帧 WAVE 有 760 条 1 px 竖条、每条一次 `LCD_FillRect`（DMA2D R2M 启动/停止开销），XY 每帧 500+ 次 `LCD_DrawLine`。改为**直接写帧缓冲**（基址读 `LTDC_Layer1->CFBAR`，RGB565 逐像素写；非 RGB565 或地址不在 SDRAM 时自动退回驱动函数），页面级清屏仍走 DMA2D。同时在地面状态行新增 `in/out/draw/loop` 四个实测值，用于区分"源端慢""画得慢""主循环被占"。编译链接 0 Error，RO 50 416 B / RW+ZI 29 576 B。新帧率与耗时仍需上板确认。
- 追加（提交帧率仍低，`viz_link.c/h` + `viz_view.c`）：上板反馈 `in` 只有 5–9。检查发现 `VizLink_Error` 之后的重武装有 **100 ms 退避**（照抄 115200 控制链路的做法），而 HAL 在任一帧错/噪声/溢出错误时都会停掉 DMA，于是每错一次白丢 ≈5 帧；按每秒 6 次错误计算正好落在 6 fps。改为 **2 ms 立即重武装**，重武装保留环形缓冲内已收字节、只归零 DMA 窗口；环形缓冲 8 KB → **16 KB**（≈65 ms）。地面状态行增加自动判断 `[NO LINK]/[SRC SLOW]/[UART ERR]/[RING OVF]/[CRC ERR]/[DRAW SLOW]` 与 `err`、`rst` 计数。编译链接 0 Error，RO 50 868 B / RW+ZI 37 784 B。该假设仍需上板用新诊断行确认。
- 追加（**真正的根因**，`viz_frame.c/h` + `viz_link.c` + 测试）：上板进一步反馈 `rx` 53 KB/s、`err`/`rst` 均为 0，但 WAVE 的 `in` 只有 7。新增"整块流"主机用例（按 `viz_top.sv` 的真实顺序 20 个 WAVE+SPEC+XY 块、STAT 每 4 块、64 字节分片喂入）复现为 **WAVE 20/20、SPEC 0/20、XY 20/20、STAT 0/20**：`VizParser_Feed` 在候选缓冲将满时只复制一部分就先返回，而 `Pump()` 只调用一次、把未消费的剩余字节当作已处理丢弃——每组装一个 518 字节帧就丢 56 字节，正好打坏紧随其后的那一帧。改为 `VizParser_Feed(..., uint16_t *consumed)` 回报本次消费字节数，`Pump()` 用该值续喂，直到整块吃完。修复后同一用例 20/20/20/5 全过。编译链接 0 Error，RO 51 332 B / RW+ZI 38 008 B。
- 追加（**XY 页可读性**，仅 `viz_view.c`）：按 `xy_scope.sv` 的定义在页面顶部用两种颜色标出 **X = x[n]**（青）与 **Y = x[n − T/4]**（琥珀，比例取自 STAT 第 6/7 字节），说明两端来自同一单声道；方框 352→**312×312**，内部加 1/4 网格与中心轴，左侧为 Y 轴、下方为 X 轴，各 5 个刻度（`+1.00 / +0.50 / 0 / −0.50 / −1.00`，按增益折算；不用 `%f`，改整数定点格式化）。刻度含义：相对 16 位满量程，`1.00 = ±32768`，1 个码 = 256 LSB，中心 = 静音（0x80）。网格线每帧重画（否则会被迹线的背景色擦出洞），文字只在清屏后画一次。排版按真实坐标做了 800×480 定位预览核对无重叠（`docs/viz_xy_layout.png`）。编译链接 0 Error。
